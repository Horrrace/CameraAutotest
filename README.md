# CameraAutotest

Camera automation release and download test repository.

## Current status

This repository currently hosts only a **redacted AE steady-state report sample**, not an application installer. See [Releases](https://github.com/Horrrace/CameraAutotest/releases) for the ZIP and its SHA-256 checksum.

The report ZIP contains photographs, grayscale/comparison images, JSON measurement data, and an Excel report. Device identifiers and image metadata were removed before publication. Photographs remain public.

The report upload is a smoke test for future GitHub Releases-based application updates. No application auto-update functionality is implemented by this release.
